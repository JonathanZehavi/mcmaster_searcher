# רשימת הזמנות McMaster

קובץ אחד שרץ על Windows או Mac בלי שום התקנה, ומחליף את גיליון ההזמנות הידני.

1. כל עובד נכנס עם שם משתמש וסיסמה ומכניס מק״ט. האתר מושך שם מוצר, יחידת מכירה (Each / Pack of N / Pair), תמונה ומחירון לפי כמות.
2. העובד בוחר כמות, פרויקט ומטרה. המחיר ליחידה והסה״כ מחושבים אוטומטית לפי מדרגת הכמות, למשל 1–11 ב-$28.46 ו-12 ומעלה ב-$25.93. שם המזמין והתאריך נרשמים אוטומטית.
3. ביום חמישי הרכש רואה את כל השורות של כולם, מייצא לאקסל בפורמט של הגיליון הקיים, מבצע את ההזמנה ב-McMaster ולוחץ "ביצעתי את ההזמנה" עם מספר ה-PO. הרשימה עוברת להיסטוריה ומתאפסת.

## הורדה

הגרסה העדכנית נבנית אוטומטית בכל שינוי בקוד:

| מערכת | קובץ |
|---|---|
| Windows | [McMasterList.exe](https://github.com/jonathanzehavi/mcmaster_searcher/releases/latest/download/McMasterList.exe) |
| Mac (M1/M2/M3/M4) | [McMasterList-mac-apple-silicon.zip](https://github.com/jonathanzehavi/mcmaster_searcher/releases/latest/download/McMasterList-mac-apple-silicon.zip) |
| Mac (Intel) | [McMasterList-mac-intel.zip](https://github.com/jonathanzehavi/mcmaster_searcher/releases/latest/download/McMasterList-mac-intel.zip) |

כל הגרסאות נמצאות ב[דף ההורדות](https://github.com/jonathanzehavi/mcmaster_searcher/releases/latest).

**הגרסה לא מתאימה לכל מחשב.** מריצים את הקובץ על מחשב אחד בלבד (ראו "כמה מחשבים" למטה). מחשבי Mac ו-Windows אחרים נכנסים אליו מהדפדפן ולא צריכים להוריד כלום.

## הפעלה ב-Windows

1. שמים את `McMasterList.exe` בתיקייה קבועה, למשל `C:\McMaster\`.
2. לוחצים עליו פעמיים. הדפדפן נפתח לבד בכתובת `http://localhost:8642`.
3. **החלון השחור הוא השרת. לא לסגור אותו.** סגירה שלו מכבה את האתר.

בהפעלה הראשונה Windows עלול להציג שתי הודעות:
- **"Windows protected your PC"**: לוחצים More info ואז Run anyway. ההודעה מופיעה כי הקובץ לא חתום דיגיטלית.
- **חומת האש (Firewall)**: לוחצים Allow רק אם מחשבים אחרים במשרד צריכים להתחבר. אם לוחצים Cancel, האתר יעבוד רק מהמחשב הזה.

כדי שהאתר יעלה אוטומטית עם הדלקת המחשב: מקישים `Win+R`, כותבים `shell:startup`, ושמים בתיקייה שנפתחת קיצור דרך לקובץ.

## הפעלה ב-Mac

1. פותחים את קובץ ה-zip ומעבירים את `McMasterList` לתיקייה קבועה.
2. לוחצים פעמיים. בפעם הראשונה macOS יחסום את הקובץ, כי הוא לא חתום אצל Apple. נכנסים ל-**System Settings ← Privacy & Security**, גוללים למטה ולוחצים **Open Anyway**. אחר כך לוחצים שוב פעמיים על הקובץ.
   דרך חלופית מה-Terminal: `xattr -dr com.apple.quarantine McMasterList`
3. נפתח חלון Terminal, והוא השרת. לא לסגור אותו.
4. צריך Chrome או Edge מותקן. עם Safari בלבד החיפוש האוטומטי לא יעבוד.

## משתמשים והרשאות

- **בהפעלה הראשונה** האתר מבקש ליצור משתמש מנהל.
- המנהל מוסיף בלשונית **ניהול** משתמשים (שם מלא, שם משתמש, סיסמה זמנית) ופרויקטים. כל משתמש יכול לשנות את הסיסמה שלו.

| | משתמש | מנהל / רכש |
|---|---|---|
| חיפוש והוספת פריטים | ✓ | ✓ |
| רואה ועורך את השורות שלו ברשימה הנוכחית | ✓ | ✓ |
| רואה את השורות שלו מההזמנה האחרונה שבוצעה | ✓ | ✓ |
| רואה ועורך את השורות של כולם, מייצא, סוגר הזמנה | | ✓ |
| היסטוריית כל ההזמנות | | ✓ |
| ניהול משתמשים ופרויקטים | | ✓ |

אפשר להגדיר כמה מנהלים, למשל גם את אחראית הרכש וגם את המנהל. המערכת לא מאפשרת להשבית או להוריד את המנהל הפעיל האחרון.

## כמה מחשבים

הרשימה נשמרת על המחשב שמריץ את הקובץ, בתיקייה `McMasterList-data` שנוצרת ליד ה-exe. כדי שכולם יעבדו על אותה רשימה:
- **מריצים את הקובץ על מחשב אחד בלבד.** כל השאר נכנסים מהדפדפן לכתובת "Other computers" שמופיעה בחלון השחור, למשל `http://192.168.1.20:8642`.
- אם כל מחשב מריץ עותק משלו, לכל מחשב תהיה **רשימה נפרדת**, ואחראית הרכש לא תראה אותן.

החיבור לאתר לא מוצפן (http), ולכן להשתמש רק ברשת המשרד.

## איך החיפוש עובד

- **חיפוש אוטומטי**: הקובץ פותח את `mcmaster.com/<מק״ט>/` ב-Chrome או ב-Edge במצב נסתר (Edge מגיע עם כל Windows) וקורא מהדף את פרטי המוצר. מתבצע חיפוש אחד בכל פעם, עם הפסקה של כמה שניות בין חיפושים. כל מק״ט נשמר, כך שבפעם הבאה הוא נטען מיד. הכפתור "רענן פרטים" כופה בדיקה חדשה.
- **אם החיפוש נכשל**: הטופס נפתח ריק עם קישור למוצר. אפשר למלא ידנית, ומה שמולא נשמר לפעם הבאה.
- **כפתור מהיר**: בלשונית "כפתור מהיר" יש כפתור שגוררים לסרגל הסימניות. בדף מוצר ב-McMaster לוחצים עליו והטופס נפתח מלא. זה רץ מהדפדפן הרגיל, ולכן אי אפשר לחסום את זה.
- **כמות ומחיר**: ב-McMaster כל מק״ט נמכר ביחידה קבועה. כשהיחידה היא "Pack of 100", הכמות היא **מספר חבילות**. כשיש מחירון לפי כמות, המחיר מתעדכן בזמן שמקלידים כמות, והמדרגה הפעילה מסומנת. במילוי ידני מקלידים מחיר ליחידה.

## כשהחיפוש האוטומטי מפסיק לעבוד

1. בכל כישלון נשמרים בתיקייה `McMasterList-data\debug\` קובץ HTML וצילום מסך של מה שהדפדפן ראה. את הקבצים האלה שולחים למי שמתחזק את הקוד.
2. התיקון מגיע כקובץ אחד, `extractor.js` (הגרסה העדכנית נמצאת תמיד [כאן](https://github.com/jonathanzehavi/mcmaster_searcher/releases/latest/download/extractor.js)). **שמים אותו בתיקייה `McMasterList-data`** שליד הקובץ. התיקון נכנס לתוקף בחיפוש הבא, בלי להוריד גרסה חדשה ובלי להפעיל מחדש.
3. כדי לחזור לזיהוי המובנה מוחקים את הקובץ.

בינתיים הכפתור המהיר והמילוי הידני ממשיכים לעבוד.

הפתרון היציב לטווח ארוך הוא [ה-API הרשמי של McMaster](https://www.mcmaster.com/help/api/), שדורש אישור על החשבון העסקי.

## הגדרות מתקדמות (משתני סביבה, לא חובה)

| משתנה | ברירת מחדל | מה עושה |
|---|---|---|
| `MCM_PORT` | `8642` | פורט |
| `MCM_HOST` | `0.0.0.0` | `127.0.0.1` מגביל לגישה מהמחשב הזה בלבד |
| `MCM_HEADLESS` | `1` | `0` מציג את חלון הדפדפן. כדאי לנסות אם יש חסימות |
| `MCM_MIN_INTERVAL` | `4` | שניות מינימום בין חיפושים |
| `MCM_BROWSER_PATH` | Chrome, ואם אין אז Edge | נתיב לדפדפן אחר |
| `MCM_DATA_DIR` | `McMasterList-data` ליד ה-exe | תיקיית הנתונים |

## פיתוח

נכתב ב-Go. דף האתר (`static/`) נארז בתוך הקובץ. הזיהוי בדף המוצר נמצא בקובץ אחד, `static/extractor.js`.

```
go test ./...          # בדיקות, כולל דפדפן אמיתי מול אתר McMaster מדומה (testdata/)
go run .               # הרצה מקומית
```

כל push ל-`master` מריץ את הבדיקות ב-GitHub Actions (`.github/workflows/build.yml`), ואם הן עוברות, בונה קבצים ל-Windows ול-Mac ומפרסם אותם ב-release `latest`.
