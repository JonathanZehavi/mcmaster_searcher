# רשימת הזמנות McMaster

קובץ אחד, `McMasterList.exe`, שרץ על Windows בלי שום התקנה. מכניסים מק״ט של McMaster-Carr, האתר מושך שם מוצר, יחידת מכירה (Each / Pack of N), מחיר ותמונה, בוחרים כמות ומוסיפים לרשימה. ביום חמישי אחראית הרכש מייצאת לאקסל (או מעתיקה להזמנה מהירה), מבצעת את ההזמנה ומסמנת "הוזמן".

## הפעלה

1. מורידים את [`dist/McMasterList.exe`](dist/McMasterList.exe) ושמים אותו בתיקייה קבועה, למשל `C:\McMaster\`.
2. לוחצים עליו פעמיים. הדפדפן נפתח לבד בכתובת `http://localhost:5000`.
3. **החלון השחור הוא השרת. לא לסגור אותו.** סגירה שלו מכבה את האתר.

בהפעלה הראשונה Windows עלול להציג שתי הודעות:
- **"Windows protected your PC"**: לוחצים More info ואז Run anyway. ההודעה מופיעה כי הקובץ לא חתום דיגיטלית.
- **חומת האש (Firewall)**: לוחצים Allow רק אם מחשבים אחרים במשרד צריכים להתחבר. אם לוחצים Cancel, האתר יעבוד רק מהמחשב הזה.

כדי שהאתר יעלה אוטומטית עם הדלקת המחשב: מקישים `Win+R`, כותבים `shell:startup`, ושמים בתיקייה שנפתחת קיצור דרך לקובץ.

## כמה מחשבים

הרשימה נשמרת על המחשב שמריץ את הקובץ, בתיקייה `McMasterList-data` שנוצרת ליד ה-exe. כדי שכולם יעבדו על אותה רשימה:
- **מריצים את הקובץ על מחשב אחד בלבד.** כל השאר נכנסים מהדפדפן לכתובת "Other computers" שמופיעה בחלון השחור, למשל `http://192.168.1.20:5000`.
- אם כל מחשב מריץ עותק משלו, לכל מחשב תהיה **רשימה נפרדת**, ואחראית הרכש לא תראה אותן.

אין סיסמה, ולכן להשתמש רק ברשת המשרד.

## איך החיפוש עובד

- **חיפוש אוטומטי**: הקובץ פותח את `mcmaster.com/<מק״ט>/` ב-Chrome או ב-Edge במצב נסתר (Edge מגיע עם כל Windows) וקורא מהדף את פרטי המוצר. מתבצע חיפוש אחד בכל פעם, עם הפסקה של כמה שניות בין חיפושים. כל מק״ט נשמר, כך שבפעם הבאה הוא נטען מיד. הכפתור "רענן פרטים" כופה בדיקה חדשה.
- **אם החיפוש נכשל**: הטופס נפתח ריק עם קישור למוצר. אפשר למלא ידנית, ומה שמולא נשמר לפעם הבאה.
- **כפתור מהיר**: בלשונית "כפתור מהיר" יש כפתור שגוררים לסרגל הסימניות. בדף מוצר ב-McMaster לוחצים עליו והטופס נפתח מלא. זה רץ מהדפדפן הרגיל, ולכן אי אפשר לחסום את זה.
- **כמות**: ב-McMaster כל מק״ט נמכר ביחידה קבועה. כשהיחידה היא "Pack of 100", הכמות היא **מספר חבילות**.

## כשהחיפוש האוטומטי מפסיק לעבוד

בכל כישלון נשמרים בתיקייה `McMasterList-data\debug\` קובץ HTML וצילום מסך של מה שהדפדפן ראה. עם הקבצים האלה מעדכנים את הזיהוי בקובץ `static/extractor.js` ובונים את ה-exe מחדש. בזמן הזה הכפתור המהיר והמילוי הידני ממשיכים לעבוד.

הפתרון היציב לטווח ארוך הוא [ה-API הרשמי של McMaster](https://www.mcmaster.com/help/api/), שדורש אישור על החשבון העסקי.

## הגדרות מתקדמות (משתני סביבה, לא חובה)

| משתנה | ברירת מחדל | מה עושה |
|---|---|---|
| `MCM_PORT` | `5000` | פורט |
| `MCM_HOST` | `0.0.0.0` | `127.0.0.1` מגביל לגישה מהמחשב הזה בלבד |
| `MCM_HEADLESS` | `1` | `0` מציג את חלון הדפדפן. כדאי לנסות אם יש חסימות |
| `MCM_MIN_INTERVAL` | `4` | שניות מינימום בין חיפושים |
| `MCM_BROWSER_PATH` | Chrome, ואם אין אז Edge | נתיב לדפדפן אחר |
| `MCM_DATA_DIR` | `McMasterList-data` ליד ה-exe | תיקיית הנתונים |

## פיתוח

נכתב ב-Go. דף האתר (`static/`) נארז בתוך ה-exe.

```
go test ./...                                                     # בדיקות מול אתר McMaster מדומה (testdata/)
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o dist/McMasterList.exe .
```
