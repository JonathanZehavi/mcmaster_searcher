# רשימת הזמנות McMaster

אתר פנימי שרץ על מחשב במשרד. מכניסים מק״ט של McMaster-Carr, האתר מושך שם מוצר, יחידת מכירה (Each / Pack of N), מחיר ותמונה, בוחרים כמות ומוסיפים לרשימה. ביום חמישי אחראית הרכש מייצאת את הרשימה לאקסל (או מעתיקה להזמנה מהירה), מבצעת את ההזמנה ומסמנת "הוזמן".

## התקנה (Windows, פעם אחת)

1. להתקין [Python 3.10+](https://www.python.org/downloads/) ולסמן **"Add python.exe to PATH"**.
2. לוודא ש-Google Chrome מותקן. החיפוש האוטומטי משתמש בו.
   אם אין Chrome: `.venv\Scripts\python -m playwright install chromium`
3. ללחוץ פעמיים על `run.bat`. בהרצה הראשונה הוא מתקין את מה שצריך, ואז פותח את `http://localhost:5000`.

כדי להפעיל אוטומטית עם הדלקת המחשב: לשים קיצור דרך ל-`run.bat` בתיקייה `shell:startup`.

## איך זה עובד

- **חיפוש אוטומטי**: השרת פותח את `mcmaster.com/<מק״ט>/` ב-Chrome נסתר וקורא מהדף שם, יחידה, מחיר ותמונה. מתבצע חיפוש אחד בכל פעם, עם הפסקה של כמה שניות בין חיפושים. כל מק״ט נשמר בזיכרון, כך שבפעם הבאה הוא נטען מיד ובלי פנייה ל-McMaster. הכפתור "רענן פרטים" כופה בדיקה חדשה.
- **אם החיפוש נכשל** (חסימה, או שינוי במבנה האתר): הטופס נפתח ריק עם קישור למוצר. אפשר למלא ידנית או להשתמש בכפתור המהיר. מה שמולא ידנית נשמר לפעם הבאה.
- **כפתור מהיר (bookmarklet)**: בלשונית "כפתור מהיר" יש כפתור שגוררים לסרגל הסימניות. כשנמצאים בדף מוצר ב-McMaster ולוחצים עליו, הפרטים נשלחים לטופס כאן. זה עובד מהדפדפן הרגיל, ולכן אי אפשר לחסום את זה.
- **כמות**: ב-McMaster כל מק״ט נמכר ביחידה קבועה. כשהיחידה היא "Pack of 100", הכמות היא **מספר חבילות**, והטופס מציין את זה.

## יום חמישי – אחראית הרכש

1. **ייצוא לאקסל**: קובץ עם מק״ט, שם, יחידה, כמות, מבקש, הערה וקישור.
2. **העתק להזמנה מהירה**: מעתיק שורות בפורמט `מק״ט<TAB>כמות` להדבקה בהזמנה לפי מק״ט באתר McMaster.
3. **סמן הכל כ"הוזמן"**: הפריטים עוברים ללשונית "הזמנות קודמות" והרשימה מתנקה.

## גישה ממחשבים אחרים ברשת

כברירת מחדל האתר זמין רק מהמחשב עצמו. כדי לפתוח אותו לרשת המשרד, מגדירים לפני ההרצה `set MCM_HOST=0.0.0.0` ונכנסים מהמחשבים האחרים לכתובת `http://<IP-של-המחשב>:5000`. **אין סיסמה**, ולכן לעשות את זה רק ברשת פנימית.

## הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | מה עושה |
|---|---|---|
| `MCM_HOST` / `MCM_PORT` | `127.0.0.1` / `5000` | כתובת השרת |
| `MCM_HEADLESS` | `1` | `0` מציג את חלון ה-Chrome. כדאי לנסות אם יש חסימות |
| `MCM_MIN_INTERVAL` | `4` | שניות מינימום בין חיפושים ב-McMaster |
| `MCM_TIMEOUT` | `25` | זמן המתנה מקסימלי לטעינת דף |
| `MCM_BROWSER_CHANNEL` | `chrome` | איזה דפדפן מותקן להפעיל (`chrome`, `msedge`) |
| `MCM_DATA_DIR` | `data` | איפה נשמרים מסד הנתונים, התמונות והדיבאג |

## כשהחיפוש האוטומטי מפסיק לעבוד

McMaster לא מספקים מבנה דף קבוע. כל הזיהוי נמצא בקובץ אחד: `static/extractor.js`. בכל כישלון נשמרים בתיקייה `data/debug/` קובץ HTML וצילום מסך של מה שהדפדפן ראה. עם הקבצים האלה אפשר לעדכן את הזיהוי. בזמן שזה מתוקן, הכפתור המהיר והמילוי הידני ממשיכים לעבוד.

הפתרון היציב לטווח ארוך הוא [ה-API הרשמי של McMaster](https://www.mcmaster.com/help/api/), שדורש אישור על החשבון העסקי. אם תקבלו גישה, צריך להחליף רק את `scraper.py`.

## פיתוח

```
pip install -r requirements.txt -r requirements-dev.txt
pytest
```
הבדיקות מריצות אתר McMaster מדומה מקומי (`tests/fixtures`). הן לא פונות לאתר האמיתי.
